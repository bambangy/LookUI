Text Formatting (icon-only grouped)

Dropdown Caret & Disabled

Dense

Flat (no border/bg)

Composable — Editor toolbar (lkToolbar)

Built from an items array: toggles (aria-pressed), an exclusive align group, a menu (lkPopupProxy), separator, spacer and a debounced search. Use Tab to enter, then ← → Home End.

Composable — Embedded components

lkDropdown, lkSwitch, lkCheckbox, lkDate, lkTextbox and lkChip are created and owned by the toolbar — tb.get(id) returns the live instance.

Composable — Runtime API

Composable — Enhance existing markup

lkToolbar('#tb-markup') on markup with no items: adds role="toolbar", aria-label and roving arrow-key focus.

JavaScript — lkToolbar composable

// lkToolbar(opts) | lkToolbar(target, opts) | lkToolbar('#existing-toolbar')
const tb = Look.lkToolbar({
  mount: document.querySelector('#host'),   // optional; or place tb.el yourself
  ariaLabel: 'Formatting',
  variant: 'default',        // 'default' | 'primary' | 'dark' | 'flat'
  dense: false,
  align: 'start',            // 'start' | 'center' | 'end' | 'between'
  wrap: true,                // true (wrap) | 'scroll' | false
  items: [
    { id: 'bold', type: 'button', icon: 'bold', text: 'Bold', iconOnly: true, toggle: true },
    { type: 'group', items: [
      { id: 'left',  type: 'button', icon: 'align-left',  text: 'Left',  iconOnly: true, group: 'align', active: true },
      { id: 'right', type: 'button', icon: 'align-right', text: 'Right', iconOnly: true, group: 'align' },
    ] },
    { type: 'separator' },
    { id: 'insert', type: 'menu', text: 'Insert', icon: 'plus', items: [
      { text: 'Image', icon: 'image', onClick: (mi, tb) => {} },
      { separator: true },
      { text: 'Link', icon: 'link', shortcut: 'Ctrl+K' },
    ] },
    { type: 'text', text: 'Font' },
    { id: 'font', type: 'dropdown', width: 140, options: { items: ['Inter', 'Georgia'], value: 'Inter' } },
    { id: 'wrap', type: 'switch', label: 'Wrap', checked: true, onChange: (checked) => {} },
    { id: 'due', type: 'date', placeholder: 'Due date', options: { min: new Date() } },
    { type: 'spacer' },
    { id: 'q', type: 'search', placeholder: 'Search…', debounce: 250, onSearch: (value) => {} },
    { type: 'custom', render: (container, tb) => myNode },   // or return { el, destroy }
  ],
  onAction(item, event, tb) { console.log(item.id, event.type); },
});

tb.get('font').value = 'Georgia';       // live lkDropdown instance
tb.get('bold').active;                  // button wrapper: el, active, enabled, hidden, text, click()
tb.getEl('q');                          // outer element of the item
tb.add({ id: 'save', type: 'button', icon: 'save', text: 'Save' }, 0);
tb.setActive('bold', true);
tb.setDisabled('insert', true);
tb.setHidden('due', true);
tb.remove('save');
tb.setItems([...]); tb.clear();
tb.hidden = false; tb.enabled = false; tb.dense = true;
tb.destroy();   // destroys owned components, popups, listeners; removes the root it created
