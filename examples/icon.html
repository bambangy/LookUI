JS Factory (Look.lkIcon)

Custom icons

Look.icons.register(name, svg) adds (or overrides) a glyph at runtime — both lkIcon(name) and plain lk-icon--name markup pick it up. Only the shape matters: the SVG is used as a mask and painted in currentColor.

Register

Look.icons.register('rocket', `<svg viewBox="0 0 24 24" fill="none" stroke="#000" stroke-width="1.75"
  stroke-linecap="round" stroke-linejoin="round">…</svg>`);
Look.icons.register('logo', '/img/logo-mask.svg');   // URL works too

// <span class="lk-icon lk-icon--rocket"></span>  or  Look.lkIcon('rocket')

Look.icons.has('rocket');        // true
Look.icons.names();              // ['rocket']  ({ all: true } → every name)
Look.icons.unregister('rocket');
Look.icons.reset();

Use a whole set

// { name: svg } or a Map — names are prefixed, existing defaults can be overridden
Look.icons.use({ cloud: '<svg…>', bolt: '<svg…>' }, { prefix: 'brand-' });
// → lk-icon--brand-cloud, lk-icon--brand-bolt

One-off inline glyph

const el = Look.lkIcon('sparkle', { svg: '<svg viewBox="0 0 24 24">…</svg>', color: 'warning' });

HTML

<span class="lk-icon lk-icon--close" aria-hidden="true"></span>
<span class="lk-icon lk-icon--star-fill lk-icon--lg lk-icon--warning"></span>
<span class="lk-icon lk-icon--refresh lk-icon--spin"></span>

JavaScript

const icon = Look.lkIcon('close');
const fav  = Look.lkIcon('heart-fill', { size: 'lg', color: 'negative' });
const labeled = Look.lkIcon('search', { label: 'Search' });
document.body.appendChild(icon);

// star-outline / heart-outline still work (aliases of star / heart)
