# Security Policy

## Supported versions

LookUI is pre-1.0. Security fixes go into the latest published release only.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report privately through GitHub:
**Security → Report a vulnerability** at https://github.com/bambangy/LookUI/security/advisories/new

Include the affected version, a description, and steps to reproduce. You should
get a response within 7 days.

## Verifying a release

Official releases are published to npm only as `@bambangy_/look-ui`, from this
repository via GitHub Actions, with npm provenance. On the npm package page,
check that the release shows a provenance link back to
`github.com/bambangy/LookUI`. Copies published under other names or without
provenance are not official.
