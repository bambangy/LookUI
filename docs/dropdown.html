JavaScript

const role = Look.lkDropdown('#el', {
  label: 'Role',
  name: 'role',
  placeholder: 'Pick a role…',
  clearable: true,
  items: [
    { value: 'admin',  label: 'Admin' },
    { value: 'editor', label: 'Editor' },
    { value: 'viewer', label: 'Viewer', disabled: true },
  ],
  onChange(value, { item }) {
    console.log(value, item);
  },
});

// Read / write value
role.value;            // current value
role.value = 'editor'; // programmatic set
role.selectedItem;     // full item object

5 — Remote Data via Transport (Function)

Pass transport.read as a function that returns a Promise. The dropdown loads page 1 on first open and passes { page, pageSize } to your function.

Mock API — paginated (pageSize 8)

Request log

— open dropdown to trigger first request —

Simulated latency (800 ms)

Watch the spinner appear on the trigger while loading.

JavaScript

Look.lkDropdown('#el', {
  label: 'User',
  useInput: true,
  clearable: true,
  pageSize: 10,
  transport: {
    read(payload, { signal }) {
      const { page, pageSize, q } = payload;
      // call your real API here
      return fetch(`/api/users?page=${page}&size=${pageSize}&q=${q ?? ''}`, { signal })
        .then(r => r.json());
      // Expected response shape: { items: [...], total: 120 }
      // Also accepted:           { data: [...], total: 120 }
      //                          [...array...] (no total = no infinite scroll)
    },
  },
});

6 — Server-side Search (server.filter)

Set server: { filter: true } to forward the search query to transport.read as a query parameter (default param name: q, configurable via searchParam). Each keystroke resets to page 1 and re-fetches.

Server-filtered search

Request log — watch q= appear when you type

— open and type to see server filter requests —

JavaScript

Look.lkDropdown('#el', {
  label: 'Product',
  useInput: true,
  clearable: true,
  pageSize: 10,
  server: { filter: true },   // push search text to server
  searchParam: 'q',           // default — matches payload key
  transport: {
    read: '/api/products',    // GET /api/products?page=1&pageSize=10&q=widget
  },
});

Set infinite: true alongside transport.read. As you scroll the options list near the bottom (60 px threshold), the next page loads and appends to the list automatically.

Look.lkDropdown('#el', {

8 — Paginated Value Resolution (selectedParam)

When a value is pre-set and items are paginated, LookUI injects a selected=<value> parameter into every transport.read request. The server can use this hint to guarantee the selected item appears in the response — even if it falls on page 3. If the server ignores the hint the raw value is shown as a ghost label.

Pre-selected value on a remote paginated list

Request log — notice selected= in every request

— open dropdown to see selected= in requests —
value = 99 (pre-set)

JavaScript — server receives selected= on every page fetch

Look.lkDropdown('#el', {
  label: 'Record',
  value: 99,                  // pre-selected value
  clearable: true,
  infinite: true,
  pageSize: 10,
  server: {
    selected: true,           // default: true — inject selected param
  },
  selectedParam: 'selected',  // default param name
  transport: {
    read(payload, { signal }) {
      // payload = { page: 1, pageSize: 10, selected: 99 }
      // Server guarantees item 99 appears in the response.
      return myApi.getRecords(payload, { signal });
    },
  },
});

// Disable the hint if your server doesn't support it:
// server: { selected: false }

9 — Programmatic Control

Open, close, set items, set value — all from JavaScript.

Runtime API

—

JavaScript — full API reference

const dd = Look.lkDropdown('#el', opts);

// Open / close
dd.open();
dd.close();

// Value
dd.value;                   // get current value
dd.value = 'react';         // set programmatically (looks up in localItems)
dd.selectedItem;            // full item object for the selected value

// Items
dd.items;                   // get current items array (copy)
dd.items = newArray;        // replace all items

// States
dd.disabled = true;
dd.readonly = true;
dd.required = false;
dd.hidden   = true;
dd.enabled;                 // same as !disabled (from applyBase)

// Form
dd.name;                    // get/set hidden input name
dd.label;                   // get/set label text

// Validation
dd.setError('Required');
dd.clearError();

// Remote
dd.load();                  // manually (re)load from transport

// Lifecycle
dd.destroy();

12 — Multiple Selection (chips)

Set multiple: true (or enhance a native <select multiple>). Picks stay open, selected values render as lkChips, × or Backspace removes them, and the form submits one value per selection.

Searchable + clearable

maxChips: 2 + chipColor

Native <select multiple>

Dense & disabled

JavaScript

const skills = Look.lkDropdown('#el', {
  label: 'Skills',
  name: 'skills',          // submits skills=a&skills=b
  multiple: true,           // alias: multiselect
  useInput: true,
  clearable: true,
  maxChips: 3,              // then a "+N" chip
  chipColor: 'primary',     // any lkChip color
  closeOnSelect: false,     // default in multiple mode
  items: SKILLS,
  value: ['design', 'sales'],
  onChange(values, { items }) { console.log(values, items); },
});

skills.value;               // ['design', 'sales']
skills.value = ['legal'];   // replace selection
skills.selectedItems;       // [{ value, label }, …]
