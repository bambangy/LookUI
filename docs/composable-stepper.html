Stepper

lkStepper(target, opts) — a multi-step flow with validation, lazy panels and Back / Next / Finish

Wizard with validation (linear)

Step 1 validates its fields, step 2 an async validate() (type ok), step 3 is optional. Later steps are locked until the one before is done; finished steps can be clicked to go back.

Vertical, non-linear, lazy URL content

JavaScript

const wizard = Look.lkStepper('#wizard', {
  linear: true,                         // only the next step is reachable by click
  steps: [
    { id: 'account', title: 'Account', description: 'Who are you?',
      content: (panel) => buildAccountForm(panel),
      fields: [email, password] },      // validated (async rules awaited) when leaving forward
    { id: 'plan', title: 'Plan', content: { url: '/partials/plan.html' },   // lazy: fetched on first visit
      validate: async () => (await planAvailable()) || 'That plan is full' },
    { id: 'extras', title: 'Extras', optional: true, content: 'Anything else?' },
    { id: 'confirm', title: 'Confirm', content: { template: '#confirm-tpl' } },
  ],
  beforeChange: (next, { prev, direction, source }) => true,    // false vetoes, a step id / index redirects
  onChange(step, { source, prev }) { console.log(prev.id, '→', step.id, source); },
  onComplete({ component }) { save(); },
});

await wizard.next();  wizard.goTo('plan');  wizard.setStatus('plan', 'error');
wizard.current = 0;   // silent
wizard.destroy();     // enhanced markup is put back exactly
