Textbox

lkTextbox(el, opts) — wraps <input> or <textarea>

Live Demo

HTML

<input id="email" type="email" />
<textarea id="notes"></textarea>

JavaScript

// Basic — auto-creates .lk-field wrapper with label
const email = Look.lkTextbox('#email', {
  label: 'Email address',
  name: 'email',
  type: 'email',
  required: true,
});

// Get / set value
email.value;                  // current value
email.value = 'user@example.com';

// Validation
email.setError('Invalid email format');
email.clearError();

// Properties
email.label = 'Work email';  // update label text
email.required = true;
email.readonly = false;
email.enabled = false;        // disable
email.hidden = true;          // hide

// Cleanup
email.destroy();

External labels & required marker

Every form component finds its existing <label for="…"> (or a wrapping <label>), keeps its text in sync with .label, and adds a red asterisk while the field is required. A label with data-required / data-mandatory makes the field required.

HTML

<label for="name">Full name</label>
<input id="name" />

<label for="country" data-mandatory>Country</label>
<select id="country">…</select>

JavaScript

const name    = Look.lkTextbox('#name', { required: true }); // external label gets *
const country = Look.lkDropdown('#country');                // required from data-mandatory

name.required = false;   // asterisk removed (alias: name.mandatory)
name.label = 'Legal name'; // updates every label pointing at the control
name.labels;             // [HTMLLabelElement, …]
name.refreshLabels();    // re-scan after labels are rendered later
// opt out of the marker: Look.lkTextbox('#x', { required: true, requiredMark: false })
