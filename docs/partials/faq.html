Does LookUI need a build step?

No. One CSS file and one JS file; call the factories on your markup.

Can tab content come from the server?

Yes — give the tab a url. This answer came from partials/faq.html (only #faq).

Are scripts in loaded HTML executed?

Not by default. Pass scripts: true for trusted pages.
