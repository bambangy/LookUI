Accordion

lkAccordion(el, opts) — a group of collapsible lkCard panels, single or multiple open

Single open (existing markup)

Three .lk-card elements already in the page. multiple: false (the default) and collapsible: false keep exactly one panel open — opening one slides the previous one shut at the same time, and the last one can't be closed by clicking its own header.

Shipping
Free over $50, otherwise a flat $4.99. Delivery in 2–5 business days.
Returns (disabled item)
Accepted within 30 days, unused and in original packaging.
Warranty
12 months against manufacturing defects.

Multiple open, built from items, flush variant

The container starts empty; the cards are built from opts.items. multiple: true lets any number of panels stay open, and variant: 'flush' drops the outer card border/gap in favor of a single divider between rows (good for a sidebar FAQ).

Variants

separated (default)

bordered

flush

Guard — veto a close with beforeToggle

The "Terms" panel below refuses to close while its checkbox is unchecked — beforeToggle returns false and the toggle (and the DOM event lk:before-toggle) is cancelled.

HTML — existing cards

<div id="faq">
  <div class="lk-card">
    <div class="lk-card__header"><div class="lk-card__title">Shipping</div></div>
    <div class="lk-card__body">Free over $50.</div>
  </div>
  <div class="lk-card" data-disabled>…</div>
</div>

JavaScript

const acc = Look.lkAccordion('#faq', {
  multiple: false,
  collapsible: true,
  variant: 'separated',       // 'separated' | 'bordered' | 'flush'
  open: 0,                    // index / id / array of them, initially open
  beforeToggle(nextOpen, { item, source, component, reason }) {
    if (reason === 'sibling') return true;   // a sibling being closed by single-mode
    return true;                              // false cancels the whole toggle
  },
  onChange(openIds, { source, component, item, opened, closed }) {
    console.log(openIds, source);             // source: 'click' | 'key' | 'api'
  },
});

acc.open('shipping');   // by id, index or item reference
acc.toggle(1);
acc.openAll();           // no-op unless multiple: true
acc.add({ title: 'New question', content: 'Answer…' });
acc.destroy();           // restores the original markup
