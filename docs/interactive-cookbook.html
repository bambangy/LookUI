Recipe 1 — Customer sign-up form

lkTextbox · lkPhone (flag + dial code + digits) · lkDate on a read-only textbox · lkTextPop (pick the sales rep from a searchable grid) · lkDropdown multiple with maxChips · lkCheckbox. Submit validates every field with setError() and shows the payload in an lkDialog.

Live value (updates as you type / pick)


        

      

    

  


  
  

    
Recipe 2 — Orders: master–detail on one lkDataSource

    

      One data source feeds the grid, the status summary chips and the detail card. The grid edits in a popup whose fields
      are LookUI components (columns[].editor): a lkTextPop customer lookup, a templated status dropdown,
      lkPhone, a date picker, a number box and a switch. The status filter outside the grid calls grid.filter().

Recipe 3 — Bulk approval pipeline

    

      Select invoices (checkbox column) → the ping badge counts them → lkDialog.question confirms →
      lkInnerLoading covers the card while lkProgress steps through each request (≈20% fail at random) →
      rows are updated through the data source → an lkToast summarizes the result.
