Table

lkTable(target, opts) — data grid bound to lkDataSource, no markup needed

1 — Local data, column menu & inline editing

Each header has a ⋮ menu (lkPopupProxy) to sort, filter and show/hide columns — the icon turns primary while the column is sorted or filtered. Edit turns the row into editors (Enter saves, Esc cancels); Add new inserts a blank row. The grid builds everything inside an empty <div>.

HTML

<div id="grid"></div>

JavaScript

const grid = Look.lkTable('#grid', {
  dataSource: { data: employees, pageSize: 10 },   // lkDataSource options…
  columns: [
    { selectable: true },
    { field: 'name', title: 'Name', width: 180 },
    { field: 'dept', title: 'Department' },
    { field: 'salary', title: 'Salary', type: 'number', format: (v) => '$' + v.toLocaleString(),
      validation: { required: true, min: 1000 } },
    { field: 'active', title: 'Status', type: 'boolean',
      template: (row) => `<span class="lk-chip lk-chip--dense lk-chip--${row.active ? 'positive' : 'secondary'}">…</span>` },
    { field: 'joined', title: 'Joined', type: 'date' },
    { command: ['edit', 'destroy'], width: 190 },   // added automatically when editable
  ],
  sortable: { mode: 'multiple' },        // or true / false
  pageable: { pageSizes: [5, 10, 25] },  // or true
  filterable: true,                      // ⋮ column menu; { mode: 'row' } for a filter row
  columnMenu: true,                      // sort / filter / column visibility
  editable: 'inline',                    // or 'popup' / { mode, createAt: 'bottom', title }
  toolbar: ['create', 'search'],
  height: 420,                           // scroll body, sticky header
  striped: true,
  onChange({ selectedRows, selectedKeys }) {},
  onRowClick({ row }) {},
  onDataBound({ items }) {},
});

grid.dataSource.add({ id: 99, name: 'New' });   // grid re-renders from the data source
grid.selectedRows;  grid.select([1, 2]);  grid.clearSelection();
grid.hideColumn('dept');  grid.showColumn('dept');  grid.search('ana');
grid.filter('salary', { op: 'gte', value: 5000 });  grid.sort('name', 'desc');  grid.clearFilters();
grid.editRow(12);  grid.addRow({ dept: 'Sales' });  grid.saveRow();  grid.cancelEdit();
grid.destroy();

// Column editing options
{ field: 'dept', values: ['Design', 'Sales'] }            // select editor
{ field: 'code', validate: (v) => /^[A-Z]{3}$/.test(v) || '3 capital letters' }
{ field: 'notes', editor(container, { value, setValue }) { /* custom editor */ } }
{ field: 'id', editable: false }                          // key column is read-only by default

2 — Remote data (shared lkDataSource)

Pass an existing lkDataSource. With server.paging / sort / filter every query change triggers a read (stale responses are dropped). This demo fakes the server with a 400 ms delay.

JavaScript

const orders = Look.lkDataSource({
  transport: { read: '/api/orders' },          // GET ?page=1&pageSize=10&sort=…&filter=…
  server: { paging: true, sort: true, filter: true },
  pageSize: 10,
});

Look.lkTable('#grid', {
  dataSource: orders,                          // or the same options object
  columns: [
    { field: 'id', title: 'Order', width: 100 },
    { field: 'customer', title: 'Customer' },
    { field: 'total', title: 'Total', type: 'number' },
  ],
  pageable: true,
  filterable: true,
  toolbar: ['search'],                         // server receives filter.$search
});

3 — Popup editing

editable: 'popup' edits in an lkDialog form (every editable column, hidden ones included). The data source here has create/update transports with a 500 ms delay; a name containing fail is rejected by the "server" — the change rolls back and the dialog shows the error. A SKU that already exists (e.g. HW-101) is rejected with field errors (throw { message, errors: { sku: [...] } }, like a 422 body): the message appears under the SKU field.

JavaScript

Look.lkTable('#grid', {
  dataSource: Look.lkDataSource({
    data: products,
    transport: { create: '/api/products', update: { url: '/api/products/{id}', method: 'PATCH' } },
  }),
  columns: [
    { field: 'sku', title: 'SKU', validation: { required: true, pattern: /^[A-Z]{2}-\d{3}$/, message: 'Format: AB-123' } },
    { field: 'name', title: 'Product', validation: { required: true } },
    { field: 'category', values: ['Hardware', 'Software', 'Service'] },
    { field: 'price', type: 'number', validation: { min: 0 } },
    { field: 'internalNote', hidden: true },   // still editable in the popup
  ],
  editable: { mode: 'popup', title: ({ isNew }) => (isNew ? 'New product' : 'Edit product') },
  toolbar: ['create'],
});

3b — Editors built from LookUI components

columns[].editor accepts a component name ('dropdown', 'date', 'switch', 'rating', 'phone', 'number', 'textbox', 'textarea', 'checkbox'), { type, options } to pass that component's own options (searchable dropdown, multiple chips, item templates…), or { component, options } for any factory with the (el, opts) contract — e.g. Look.lkTextPop. Editors are destroyed with the row / dialog, so their floating panels never leak.

Popup (same columns, editable: 'popup')

JavaScript

Look.lkTable('#grid', {
  dataSource: { data: tickets, pageSize: 5 },
  editable: 'inline',                                    // or 'popup'
  toolbar: ['create'],
  columns: [
    { field: 'title', editor: 'textbox', validation: { required: true } },
    { field: 'status', editor: { type: 'dropdown', options: {
        items: STATUSES,                                 // [{ value, label, color }]
        template: (item) => statusChip(item),            // lkDropdown item template
      } } },
    { field: 'tags', editor: { type: 'dropdown', options: { items: TAGS, multiple: true, maxChips: 2 } } },
    { field: 'assignee', editor: { component: Look.lkTextPop, options: {
        dataSource: people, columns: [{ field: 'name' }, { field: 'team' }],
      } } },
    { field: 'phone', editor: { type: 'phone', options: { preferred: ['ID'] } } },
    { field: 'due', type: 'date', editor: 'date' },
    { field: 'priority', type: 'number', editor: { type: 'rating', options: { max: 5 } } },
    { field: 'urgent', type: 'boolean', editor: 'switch' },
    // options can depend on the record:
    { field: 'owner', editor: { type: 'dropdown', options: ({ row }) => ({ items: ownersFor(row?.team) }) } },
  ],
});
