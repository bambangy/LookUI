Overridable events

before<Action> guards — veto, delay or replace what a user action is about to do

The idea

Callbacks like onChange tell you what happened. Every user-driven action in LookUI also asks first: before it happens, a guard can stop it, wait for something asynchronous, or change what it will do. Each guard is available twice — as an option callback and as a cancelable DOM event — and both use the same name:

Option callbackDOM eventReceives
beforeChange(payload, ctx)lk:before-changepayload = what is about to happen (new value, files, page…), ctx = { source, component, … }
beforeClose(ctx)lk:before-closeactions without a payload get ctx only (ctx.reason says why)

The DOM event bubbles from the component's element, so one listener on a <form> or document can govern a whole area; event.detail holds ctx and payload.

What a guard can do

Do thisCallbackDOM eventResult
Cancelreturn falseevent.preventDefault()Nothing happens, the after-callback (onChange, …) does not fire, the UI stays as it was.
Waitreturn a Promise—The action waits; resolving false cancels, anything else continues. A rejection or a thrown error counts as a veto.
Replacereturn a new valueset event.detail.payloadThe action runs with your value (a filtered file list, a corrected page number…), where the action carries one.
Continueundefined / truedo nothingThe action runs unchanged.

Programmatic changes that are not user actions (component.value = x, card.expanded = true) stay silent and unguarded. Methods that mirror a user action (upload.add(), card.close()) pass through the guard with source: 'api'.

Option callbacks

Look.lkUpload('#files', {
  multiple: true,
  // replace the payload
  beforeAdd(files, { source }) {
    return files.filter((f) => !f.name.endsWith('.exe'));
  },
  // veto, asynchronously
  async beforeRemove(files) {
    return await askUser('Remove ' + files.length + ' file(s)?');   // false keeps them
  },
});

Look.lkCard('#details', { beforeToggle: (nextOpen) => nextOpen || confirm('Close?') });

DOM events (works with plain addEventListener / MVC)

document.addEventListener('lk:before-change', (e) => {
  const { component, source, payload } = e.detail;
  if (component.el.closest('[data-readonly]')) e.preventDefault();        // cancel
  if (Array.isArray(payload)) e.detail.payload = payload.slice(0, 3);    // replace
});
