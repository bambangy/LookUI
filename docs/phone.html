Phone

lkPhone(el, opts) — country dropdown (flag + dial code) joined to a digits-only textbox

Basic

Type digits only — anything else is stripped. Paste +65 9123 4567 to switch the country automatically.

Flags, preferred countries & states

Form & validation

JavaScript

const phone = Look.lkPhone('#phone', {
  label: 'Phone number',
  name: 'phone',             // hidden input carries the E.164 value (+6281234567890)
  country: 'ID',             // initial country (ISO 3166-1 alpha-2)
  preferred: ['ID', 'SG', 'MY'],
  flag: 'image',             // 'image' (flagcdn.com) | 'emoji' | 'code' | false
  required: true,
  onChange(value, ctx) { console.log(value, ctx.source, ctx.country, ctx.number, ctx.valid); },
});

phone.value = '+6281234567890';   // detects Indonesia, fills 81234567890
phone.country = 'SG';
phone.valid;                      // length check against minDigits / maxDigits
phone.destroy();
