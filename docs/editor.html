Editor

lkEditor(textarea, opts) — WYSIWYG rich-text HTML editor with a raw-source view and a built-in sanitizer

Full toolbar

Every control, left to right: Undo / Redo; a paragraph style dropdown (Paragraph, Heading 1–6, Blockquote, Preformatted — formatBlock); a font size dropdown (Small / Normal / Large / Huge); Bold / Italic / Underline / Strikethrough toggles; text color and highlight color (each opens a popup with an lkColor picker and runs foreColor / hiliteColor); align left / center / right / justify; numbered and bullet lists; Link (opens a mini-form popup — URL + "open in new tab" — Apply wraps the selection in <a href>, Remove runs unlink); Code block (wraps the selection, or the current block, in <pre><code>); Clear formatting; and, right-aligned, View source, which swaps the WYSIWYG surface for a raw-HTML textarea.

Source view round trip

Click View source to see the raw HTML, edit it directly, then click it again to parse the edit back into the WYSIWYG surface (through the sanitizer, since sanitize is on by default).

Insert a link

Select some text, click the link icon, type a URL (and optionally check "Open in new tab"), then Apply. Click the link icon again with the caret inside an existing link to edit or Remove it.

Sanitization — before / after

This is a best-effort, allowlist-based client-side sanitizer for display/editing safety — not a substitute for server-side sanitization of anything later rendered to other users. Click the button to load a known-bad payload through setValue() with sanitize left on; the editor only ever receives the cleaned result.

getValue(): raw vs. encoded

    

      getValue() (default) returns the raw HTML string; getValue({ encode: true }) returns
      an HTML-entity-encoded string — safe to embed where literal angle brackets would be a problem (an attribute,
      a JSON field read by a legacy system, ...). This is a plain entity-encode, not a security boundary by itself.

JavaScript

    
const ed = Look.lkEditor('#body', {
  label: 'Description',
  sanitize: true,                 // default; false disables it, or pass a fn(html) => safeHtml
  encodeForSubmit: false,          // the hidden <textarea> posts raw HTML by default
  rules: ['required'],             // checks the TEXT content, stripped of tags
  onChange(value, ctx) { console.log(ctx.source, value); },
});

ed.value;                         // get: live HTML  |  set: silent
ed.getValue({ encode: true });    // HTML-entity-encoded string
ed.setValue(encoded, { encoded: true });
ed.toggleSource();                // flip WYSIWYG <-> raw-HTML view
ed.destroy();
