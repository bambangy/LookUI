Drawer

lkDrawer(opts) — a side panel that slides in from any edge; modal or non-blocking

Sides

Sizes

Form drawer with footer buttons

The Save button validates and only closes when valid; the dropdown inside closes first on Escape.

Non-modal, resizable, async content

JavaScript

const drawer = Look.lkDrawer({
  side: 'right',                 // 'left' | 'right' | 'top' | 'bottom' | 'start' | 'end'
  size: 'md',                    // 'sm' | 'md' | 'lg' | 'full' | '30rem'
  title: 'Edit profile',
  content: { url: '/partials/profile.html', select: '#form' },   // or text, Node, (body) => …, { html }, { template }
  buttons: [
    { text: 'Cancel', closes: true },
    { text: 'Save', type: 'primary', onClick: () => save() },    // return false to keep it open
  ],
  resizable: { min: 280, max: '60vw' },
  beforeClose: (reason) => (dirty && reason !== 'api' ? confirmDiscard() : true),
  onClose(reason, component) { console.log(reason); },           // 'escape' | 'backdrop' | 'close' | 'button' | 'api'
});

drawer.close();  drawer.toggle();  drawer.setContent('…');
drawer.destroy();
