Segmented

lkSegmented(el, opts) — segmented button group (single or multiple) with a sliding indicator

Single (from items)

Focus a segment and use the arrow keys / Home / End (roving tabindex).

Multiple

Sizes, dense & block

From markup (buttons and radios)

Guard, states & validation

JavaScript

const view = Look.lkSegmented('#view', {
  items: [
    { value: 'day',   label: 'Day' },
    { value: 'week',  label: 'Week',  icon: 'calendar' },
    { value: 'month', label: 'Month', disabled: true },
  ],
  value: 'day',
  name: 'view',                // hidden input for form posts
  onChange(value, ctx) { console.log(value, ctx.source, ctx.item); },
  beforeChange(value) { return confirm('Switch view?'); },
});

view.value = 'week';           // silent
view.add({ value: 'year', label: 'Year' });
view.disable('month');
view.destroy();
