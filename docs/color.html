Color

lkColor(input, opts) — colour field with swatches, a native picker and optional opacity

Basics

Type any colour too: #f00, teal, rgb(20, 120, 200), hsl(210 50% 40%).

Display format & states

Form & validation

JavaScript

const brand = Look.lkColor('#brand', {
  alpha: true,                // opacity slider, 8-digit hex when not opaque
  clearable: true,
  format: 'hex',              // display: 'hex' | 'rgb' | 'hsl'
  swatches: ['#ef4444', { value: '#22c55e', label: 'Green' }],
  onChange(value, ctx) { console.log(value, ctx.source, ctx.rgb, ctx.hsl); },
});

brand.value;                  // '#3b82f6' | '#3b82f680' | null
brand.value = 'rebeccapurple';// silent, lenient parsing
brand.destroy();
