Time

lkTime(input, opts) — time-of-day field with a picker popup

Basics

Type a time too: 930, 9.30 pm, 21:05, 12am.

Range, step & locale

States

Form & validation

JavaScript

const start = Look.lkTime('#start', {
  format: 24,                // 12 | 24 (default: the locale's hour cycle)
  minuteStep: 5,
  seconds: false,
  min: '08:00', max: '18:00',
  onChange(value, ctx) { console.log(value, ctx.source, ctx.display, ctx.iso); },
});

start.value;                 // '14:30' | null  ('HH:mm', or 'HH:mm:ss' with seconds)
start.value = '09:15';       // silent; also accepts a Date
start.open();
start.destroy();
