Ready-made Themes

Free, drop-in LookUI themes — one extra <link>, no class, attribute or JS

How it works

Each theme below is a standalone stylesheet shipped with @lookui/core in dist/. Load it right after look.css and it's active immediately — it overrides the same --lk-* tokens your own custom theme file would, so the two compose normally (load your own overrides after the theme's file to tweak individual keys). 

<link rel="stylesheet" href="node_modules/@lookui/core/dist/look.css">
<link rel="stylesheet" href="node_modules/@lookui/core/dist/lookui-theme-candy.css">   <!-- that's it -->

Or from a CDN, pinned to a version:

<link rel="stylesheet" href="https://unpkg.com/@lookui/core@0.5.0/dist/look.min.css">
<link rel="stylesheet" href="https://unpkg.com/@lookui/core@0.5.0/dist/lookui-theme-candy.min.css">
