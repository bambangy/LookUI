Theme

Look.lkTheme(opts) — light, dark or follow the system; remembered across visits and tabs

Switch the theme of this page

A scoped dark region

Any container can carry data-theme="dark": a dark region inside a light page. (The reverse, a light region inside a dark page, is not provided.)

Always dark
Chip

Palette in use

--lk-bg --lk-bg-subtle --lk-surface --lk-primary --lk-positive --lk-warning --lk-negative --lk-info

No flash on load

The page is rendered before your script runs, so the stored theme has to be applied from an inline script in <head>, before the stylesheet. Generate it with Look.lkTheme.inlineScript({ ... }) or copy it:

<script>
(function () {
  try {
    var mode = localStorage.getItem('lk-theme') || 'system';
    var theme = mode === 'system'
      ? (matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light')
      : mode;
    var root = document.documentElement;
    root.setAttribute('data-theme', theme);
    root.style.colorScheme = theme;
  } catch (e) {}
})();
</script>
<link rel="stylesheet" href="look.css">

Without JavaScript, <html data-theme="system"> follows the OS preference by itself.

JavaScript

const theme = Look.lkTheme({
  default: 'system',           // used when nothing is stored
  onChange(mode, ctx) {        // ctx.source: 'user' | 'system' | 'api'
    console.log(mode, ctx.resolved);
  },
});

button.onclick = () => theme.toggle();    // light <-> dark
theme.set('dark');                          // 'light' | 'dark' | 'system'
theme.mode;       // what the user chose
theme.resolved;   // 'light' | 'dark' — what is applied
