Tag input

lkTagInput(el, opts) — type and press Enter to turn text into removable chips

Basic

Enter or comma adds, pasting a, b, c (or one per line) adds all, Backspace on the empty field arms the last tag and a second Backspace removes it.

Limits & validation

With suggestions

States

Form

JavaScript

const tags = Look.lkTagInput('#skills', {
  label: 'Skills',
  name: 'skills',                       // one hidden input per tag
  maxTags: 5,
  separators: ['Enter', ','],           // also 'Tab', ' ', ';' …
  transform: (t) => t.toLowerCase(),
  validateTag: (t) => /^[\w-]+$/.test(t) || 'Letters, digits and dashes only',
  source: ['javascript', 'typescript', 'rust'],   // optional suggestions
  rules: [{ minLength: 1, message: 'Add a skill' }],
  onChange(value, { source, added, removed }) { console.log(value, source); },
  onReject(rejected) { console.log(rejected); },   // return false to hide the inline message
});

tags.value;          // string[]
tags.add(['css']);
tags.destroy();
