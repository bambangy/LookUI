Floating

Look.lkFloating(opts) — a persistent element pinned to a screen corner (FAB, floating widget, chat launcher, …)

Position & visibility

A single floating action button. Switch its corner live (silent — position = is not guarded) and toggle it (guarded — see the log).

Three ways to give it content

Click a button above, then look at the bottom-left corner of the page.

Guard — veto hiding while a condition holds

This widget's beforeHide refuses to close while the checkbox below is ticked.

JavaScript

// A FAB built from a <template>
const fab = Look.lkFloating({
  position: 'bottom-right',           // 'top-left' | 'top-right' | 'bottom-left' | 'bottom-right'
  template: '#fab-template',
  onShow(c) {}, onHide(reason, c) {},
  beforeHide(reason, ctx) { return !isBusy; },  // false = refuse to hide
});

fab.position = 'top-right';           // silent, no guard
fab.toggle();
fab.setContent({ html: '<button class="lk-btn lk-btn--primary">New</button>' });
fab.destroy();

// Mount a real Look component as the content
Look.lkFloating({
  component: { component: Look.lkButton, tag: 'button', options: { onClick: () => alert('hi') } },
});
