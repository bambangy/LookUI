Guards

beforeChange runs at drop. Here the first item is pinned: moving it, or dropping anything above it, is refused and the item animates back.

  • Pinned (stays first)
  • Item A
  • Item B

JavaScript

const sortable = Look.lkSortable('#tasks', {
  handle: '.grip',              // optional: only this part starts a drag
  animation: 180,               // FLIP animation of the displaced items (ms)
  onChange(order, ctx) {        // order = ids ('data-id', else the index)
    console.log(order, ctx.source, ctx.from, '->', ctx.to);
  },
  beforeChange({ item, from, to }) {
    if (to === 0) return false; // veto: the item animates back
  },
});

sortable.getOrder();            // ['design', 'build', ...]
sortable.setOrder(['ship', 'build']);   // silent
sortable.destroy();

// Two lists that exchange items
Look.lkSortable('#todo', { group: 'board' });
Look.lkSortable('#done', { group: 'board' });
