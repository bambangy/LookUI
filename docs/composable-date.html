Composable Date

Look.lkDate(target, opts) - compact popup date/range/datetime picker

Textbox + calendar icon — displayFormat, ISO value, holidays

The textbox shows picker.display() (from displayFormat); picker.value stays a Date and picker.iso() gives the raw string, also posted by a hidden input (name). Weekends are disabled, holidays are red with a dot (hover for the name), 24–26 Dec are blocked.

Mode Playground

Ready

JavaScript

// A readonly textbox with a calendar icon; the whole field opens the picker
const due = Look.lkTextbox('#due', { label: 'Due date', readonly: true, append: Look.lkIcon('calendar', { size: 'sm' }) });
const picker = Look.lkDate(due.el.closest('.lk-input-affix'), {
  input: due,                         // writes picker.display() into the textbox
  displayFormat: 'dd MMM yyyy',       // what the user sees
  isoFormat: 'yyyy-MM-dd',            // picker.iso() (default: yyyy-MM-dd, or yyyy-MM-ddTHH:mm:ss.SSS with time)
  name: 'dueDate',                    // hidden input posting picker.iso()
  min: new Date(),
  disabledDays: [0, 6],               // no weekends
  disabledDates: [{ from: '2026-12-24', to: '2026-12-26' }],
  holidays: ['01-01', { date: '2026-08-17', label: 'Independence Day' }],
});

picker.value;      // Date (unchanged contract)
picker.display();  // '08 Oct 2026'
picker.iso();      // '2026-10-08'
picker.format("dddd, d MMMM yyyy");

// Date + time: calendar, time row and OK in one panel
Look.lkDate('#meeting', { time: true, timeFormat: 24, minuteStep: 15, displayFormat: 'dd/MM/yyyy HH:mm' });
