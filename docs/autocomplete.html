lkAutocomplete(el, opts) — a text input with a suggestion popup (ARIA combobox)

Static list & open on focus

Objects, template, hidden value, force selection

Async source (debounced, abortable, error + retry)

States

JavaScript

const city = Look.lkAutocomplete('#city', {
  label: 'City',
  source: ['Amsterdam', 'Berlin', 'Bogotá'],      // strings, objects, an lkDataSource or a function
  // source: (query, { signal }) => fetch('/api/cities?q=' + query, { signal }).then((r) => r.json()),
  textField: 'text', valueField: 'value',
  forceSelection: false,                           // true: free text reverts on blur
  rules: ['required'],
  onChange(value, { source, item }) { console.log(value, source, item); },
});

city.value;        // the text
city.item;         // the picked suggestion (null while the text is free)
city.destroy();
