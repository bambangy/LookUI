Status dialogs (SweetAlert-style)

With a type the dialog shows a large animated icon (drawn in on open) and centers its content. Every dialog pops in SweetAlert2-style and slides down on close; animation: 'calm' switches to a plain rise/fade.

Reusable dialog, async confirm & live updates

One instance created with open: false and reopened. onConfirm returns false while a fake request runs, then updates the dialog through setTitle() / setContent().

JavaScript

const dialog = Look.lkDialog({
  title: 'Delete item?',
  content: 'This action cannot be undone.',
  confirmText: 'Delete',
  cancelText: 'Cancel',
  onConfirm: () => console.log('confirmed'),
});

// Status presets (pop + animated icon)
Look.lkDialog({ type: 'success', title: 'Saved!', content: 'Your changes are live.' });
Look.lkDialog({ type: 'warning', title: 'Delete file?', confirmText: 'Delete', onConfirm: remove });

// Shorthands — destroyOnClose is on by default
Look.lkDialog.success('Saved!', 'Your changes are live.');
Look.lkDialog.error('Upload failed', 'The server rejected the file.');
Look.lkDialog.question('Discard draft?', 'You have unsaved changes.', { confirmText: 'Discard' });

// Options
//   type: 'success' | 'error' | 'warning' | 'info' | 'question'
//   animation: 'sweet' | 'calm'   (default: 'sweet' for every dialog)
//   icon: false                   (keep the layout, hide the icon)
//   confirmColor: 'negative'      (error uses negative by default)
//   showCancel                    (with a type: only question / warning show Cancel)
