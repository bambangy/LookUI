Composable Tree

Look.lkTree(target, opts) — nested data as an accessible tree view: selection, tri-state checkboxes, lazy loading, filter

Nested items, single selection, icons

Built from a plain nested items array. selectable: 'single' highlights one row at a time and fires onChange; icons sets the default branch/leaf glyph (a node's own icon field wins). Try the keyboard: Up/Down/Home/End move, Right expands (or enters the first child), Left collapses (or goes to the parent), Enter selects + onAction, and typing jumps to a matching label.

Tri-state checkboxes + multi-select

checkboxes: 'tri' propagates down (checking a folder checks every descendant) and up (a parent shows a dash when only some children are checked). Row selection (selectable: 'multiple', Ctrl/Cmd-click or Shift-click to extend) is independent of the checkboxes.

Lazy loading (loadChildren) + error retry

Neither items nor dataSource is given, so the whole tree (and every branch without a children array) loads through loadChildren(node) — called with null for the root. A spinner replaces the toggle chevron while a branch loads. The "docs" folder is wired to fail once, to show the inline retry button.

Filter

filter(text) hides every node that doesn't match (ancestors of a match stay visible and expand); clearing it restores the previous expansion exactly.

JavaScript

const tree = Look.lkTree('#files', {
  items: [{ text: 'src', children: [{ text: 'index.js' }] }, { text: 'README.md' }],
  selectable: 'single',             // false | 'single' | 'multiple' | true (= 'single')
  checkboxes: 'tri',                 // false | true | 'tri'
  icons: { branch: 'folder', leaf: 'file' },
  onChange(value, { source, node, nodes }) { console.log(value, source); },
  onToggle(open, { node, source }) {},
});

// Lazy branches: no `items` / `dataSource` — loadChildren(null) fetches the roots
Look.lkTree('#remote', {
  loadChildren: (node) => node ? fetchChildrenOf(node.value) : fetchRoots(),
});

tree.expand('src');     tree.select('readme');    tree.check('src');
tree.filter('index');   tree.reveal('index.js', true);
tree.destroy();
