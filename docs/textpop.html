TextPop

lkTextPop(el, opts) — lookup field: a searchable, read-only lkTable in a popup, single or multi select

Single select

Click (or focus + Enter) to open. Type to filter every column, click a row to pick it. Backspace clears.

Multiple select — chips with maxChips: 3

Custom display & server-style data source

JavaScript

const owner = Look.lkTextPop('#owner', {
  label: 'Owner',
  name: 'ownerId',
  dataSource: employees,          // array | lkDataSource options | lkDataSource instance
  valueField: 'id',
  textField: 'name',
  columns: [
    { field: 'id', title: 'ID', width: 70 },
    { field: 'name', title: 'Name' },
    { field: 'dept', title: 'Department' },
  ],
  onChange(value, { item }) { console.log(value, item); },
});

const reviewers = Look.lkTextPop('#reviewers', {
  multiple: true,
  maxChips: 3,                    // then a "+N" chip
  dataSource: employees,
  columns: [{ field: 'name' }, { field: 'dept' }],
});

reviewers.value = [3, 7, 9];
reviewers.selectedRows;           // full records
reviewers.destroy();
