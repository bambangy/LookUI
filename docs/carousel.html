Async content — slides from a URL

Built from slides: each slide is a content spec. The first three fetch partials/slides.html and keep one <article> each with select; the fourth is an async function. Content loads lazily (active slide ± 1), with a spinner while it arrives and Retry when it fails.

Opened from file://: browsers block fetch() there, so the URL slides show an error. Serve the folder (e.g. npx serve .) or use the GitHub Pages docs.

Markup slides with data-url

Existing markup works too: a slide with data-url (and optional data-select) loads its HTML when it comes near.

JavaScript

const carousel = Look.lkCarousel('#my-carousel', {
  index: 0,            // starting slide
  autoplay: true,
  interval: 3000,
  loop: true,          // seamless wrap (no rewind)
  swipe: true,         // pointer / touch drag
  keyboard: true,      // ←/→ when focus is inside
  pauseOnHover: true,  // autoplay also stops while the tab is hidden
  onChange(index, { source, prev }) {},
});

// Tune motion per carousel in CSS:
// #my-carousel { --lk-carousel-duration: 600ms; --lk-carousel-easing: ease-in-out; }

carousel.activeIndex;    // 0
carousel.count;          // 2
carousel.next();
carousel.prev();
carousel.goTo(1);
carousel.pause();  carousel.resume();
carousel.destroy();

Async content

// Slides from options — no markup needed (track, arrows and dots are built)
const news = Look.lkCarousel('#news', {
  slides: [
    { url: '/promo/spring.html' },                       // fetched HTML
    { url: '/promo/all.html', select: '#summer' },        // part of a page
    { html: '<h3>Raw HTML</h3>' },
    { content: async (slide) => renderCard(await api.latest()) },
  ],
  lazy: true,          // load near the active slide only (preload: 1)
  onLoad(slide, { index }) { /* enhance loaded markup */ },
});

// …or the whole list from the server
Look.lkCarousel('#news', {
  slides: async () => (await (await fetch('/api/promos')).json()).map((p) => ({ url: p.url, label: p.title })),
});

news.reload();             // fetch the active slide again
news.setSlides([...]);     // replace every slide
