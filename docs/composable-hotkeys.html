Labels for buttons and menus

Labels come from Look.lkHotkeys.format(keys) and follow the active language:

Guard

With beforeTrigger you can ignore a shortcut (and leave the browser's default untouched). Here alt+s is allowed only while the box is checked.

JavaScript

const hk = Look.lkHotkeys({
  'mod+k': (e) => openPalette(),
  'mod+shift+p': () => togglePreview(),
  'g i': () => go('inbox'),          // a sequence: press g, then i (1 s)
  '?': () => showHelp(),
  'escape': () => closeAll(),
}, { scope: document, ignoreInputs: true });

// or the array form with descriptions
Look.lkHotkeys([
  { keys: 'mod+s', handler: save, description: 'Save', allowInInputs: true },
  { keys: 'delete', handler: remove, description: 'Delete row', scope: '#grid', when: () => hasSelection() },
]);

hk.list();                           // [{ keys, label, description }]
Look.lkHotkeys.format('mod+shift+p');   // '⌘⇧P' on macOS, 'Ctrl+Shift+P' elsewhere
hk.destroy();
