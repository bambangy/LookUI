Upgrading to 0.3

One callback convention for every component — what changed and how to update your code

The convention

0.3 makes callbacks predictable before the 1.0 API freeze. Every component now follows the same four shapes:

KindShapeNotes
Value changesonChange(value, ctx)ctx is always an object with source (what caused it: 'select', 'click', 'key', 'api', …), component (the instance) and component-specific extras (item, prev, tab, …).
Open / closeonOpen(component) · onClose(reason, component)
onShow(component) · onHide(reason, component)		The instance is always passed.
Load / erroronLoad(el, ctx) · onError(error, ctx)Tabs and carousel content.
ClicksonClick(event, { component, … })Button, chip, toolbar items.

Complex components (lkTable, lkToolbar's onAction) keep a single event object, which now also contains component.

onChange fires for user actions. Setting value / checked / page from code is silent, except where a method says otherwise (lkDate.setValue(v, source), the pagination page setter report source: 'api').

Tip: use ctx.component instead of the variable you assigned the component to — some callbacks (e.g. lkList's onToggle with origin: 'init', carousel/tab content loading) can run while the factory is still returning, before your variable exists.

What still works for now

These renamed APIs keep working in 0.3 and log one console warning each. They will be removed in 1.0:

  • lkPagination option onPageChange → onChange
  • lkChip option onSelect → onChange (also inside lkToolbar chip items)
  • lkModal(trigger, modal) → lkModal(modal, { trigger })

Everything below whose arguments changed cannot be detected automatically — update those callbacks when you upgrade.

Before / after

0.2

Look.lkDropdown('#city', {
  items,
  onChange(value, item) {
    label.textContent = item.label;
  },
});

0.3

Look.lkDropdown('#city', {
  items,
  onChange(value, { item, source }) {
    label.textContent = item ? item.label : '';
  },
});

0.2

Look.lkTabs('#tabs', {
  tabs,
  onChange(name, prevName) {
    track(prevName, name);
  },
});

0.3

Look.lkTabs('#tabs', {
  tabs,
  onChange(name, { prev, source }) {
    track(prev, name);
  },
});

0.2

const modal = Look.lkModal('#open', '#dialog');
toolbar = Look.lkToolbar({
  items: [{ id: 'save', type: 'button',
    onClick(item, tb, e) { save(); } }],
});

0.3

const modal = Look.lkModal('#dialog', { trigger: '#open' });
toolbar = Look.lkToolbar({
  items: [{ id: 'save', type: 'button',
    onClick(event, { item }) { save(); } }],
});
