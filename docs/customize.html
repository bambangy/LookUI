Custom Theme File

Replace colors, spacing and sizes with your own CSS file — no build step, safe across upgrades

How it works

Every LookUI style reads its color, spacing, size, radius, shadow and motion from a CSS custom property (--lk-primary, --lk-space-4, --lk-text-base, …) defined on :root inside look.css. Your theme file defines the same keys again; because it is loaded after look.css, your values win. You never edit look.css itself, so upgrading LookUI keeps your theme.

1Create a CSS file

e.g. css/lookui-theme.css with a :root { … } block.

2Override the keys you need

Only the keys you write change; everything else keeps the default.

3Load it after look.css

One extra <link> (or import) right below LookUI's stylesheet.

Step 1 — Create the theme file

Start small. This file changes the brand color, font, corner radius, spacing and text sizes: 

/* css/lookui-theme.css — loaded after look.css */
:root {
  /* Brand color (+ its lighter/darker shades and the text color on top of it) */
  --lk-primary:          #00897b;
  --lk-primary-light:    #4db6ac;
  --lk-primary-dark:     #00695c;
  --lk-primary-contrast: #ffffff;

  /* Font */
  --lk-font-family: 'Inter', system-ui, sans-serif;

  /* Shape */
  --lk-radius:    0.375rem;
  --lk-radius-lg: 0.75rem;

  /* Spacing (used for padding, gaps and margins everywhere) */
  --lk-space-2: 0.5rem;
  --lk-space-4: 1.125rem;

  /* Text sizes */
  --lk-text-sm:   0.875rem;
  --lk-text-base: 1rem;
}

Want every key in one place? Download the full template (lookui-theme.css) — all 130+ global keys with their default values, each commented out. Uncomment only what you change, so the remaining keys keep following LookUI's defaults after upgrades.

Step 2 — Where to put and include the file

Put the file with your other stylesheets and include it directly after LookUI's CSS — before your own page styles. The order is the only rule: a later stylesheet wins for the same :root keys.

my-app/ ├─ index.html ├─ css/ │ ├─ look.css ← LookUI (or from node_modules / CDN) │ ├─ lookui-theme.css ← your theme: 2nd │ └─ site.css ← your page styles: 3rd └─ js/ └─ look.js

The keys you can replace

Current values are read live from this page. Global keys go in :root; component keys can go in :root (all instances) or on a component selector (some instances).

Making everything bigger or smaller

LookUI sizes are in rem, so there are three levels of control:

/* 1. Scale the whole UI (text, spacing, controls) — 16px is the browser default */
html { font-size: 15px; }

/* 2. Change one scale only */
:root {
  --lk-text-base: 0.9375rem;   /* body text */
  --lk-space-3:   0.625rem;    /* tighter paddings that use space-3 */
}

/* 3. One component or one area */
.lk-chip    { --lk-chip-height: 1.5rem; }
.compact    { --lk-space-2: 0.375rem; --lk-space-4: 0.75rem; }   /* everything inside .compact */

Most components also have a dense option or --dense class for a compact variant without any CSS.

Several themes and dark mode in the same file

Custom properties inherit, so a selector other than :root themes just that part of the page. Use an attribute on <html> to switch themes at runtime: 

/* lookui-theme.css */
:root { --lk-primary: #00897b; }                 /* default theme */

.theme-sunset { --lk-primary: #ef6c00; --lk-primary-dark: #b53d00; }   /* a section */

[data-theme="dark"] {                            /* dark mode */
  --lk-bg: #121218;   --lk-bg-subtle: #1b1b24;   --lk-surface: #22222d;
  --lk-text: #ececf1; --lk-text-muted: #a0a0ad;
  --lk-border: #34343f; --lk-border-strong: #4a4a57;
  --lk-secondary-dark: #cfd8dc;
}

/* follow the OS setting unless the user picked a theme */
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { /* same keys as [data-theme="dark"] */ }
}
// toggle
document.documentElement.dataset.theme = 'dark';   // or 'light'

Troubleshooting

Nothing changes? Check the order in DevTools → Elements → <head>: your file must come after look.css. In DevTools → Styles, select <html> and look for your --lk-* values; a struck-through value means another rule wins.
Old values after editing? The browser cached the file. Add a version (lookui-theme.css?v=2, asp-append-version, a bundler hash) or hard-reload.
A color looks wrong in only one component? Some components have their own keys that default to the global ones (see Component keys above) — override those, or check whether a component uses a shade (-light, -dark, -contrast) you did not set.
Don't edit look.css or use !important. Edits to look.css are lost on upgrade, and !important on a key blocks scoped themes. If you build LookUI from source, the same keys can be set at build time in src/scss/tokens/custom/*.scss — see Theming.
