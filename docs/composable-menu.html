Composable Menu

Look.lkMenu(target, opts) — dropdown / context menu with submenus, built on lkPopupProxy

Dropdown with icons, shortcuts and a submenu

Default trigger is 'click'. "Share" opens a submenu (items nested one level, right-top placement, hover-intent delay). Keyboard: Up/Down/Home/End, Right opens a submenu, Left closes it, Enter/Space activate, type-ahead, Escape closes one level at a time and returns focus to the trigger.

Ready

Checkbox & radio items

type: 'checkbox' toggles independently; type: 'radio' items sharing a group uncheck each other. Activating either keeps the menu open by returning keepOpen: true on the item, so several options can be flipped in one visit.

Ready

Context menu

trigger: 'contextmenu' opens at the pointer and suppresses the native menu. Right-click again while it is open to reposition it at the new pointer location.

Right-click anywhere in this box

Guards — veto / delay an action

"Delete" is guarded by beforeAction: it shows a confirm dialog and only lets the action through (and the menu close) if the user confirms. A plain manual menu is also opened here with Look.lkMenu({ items }).open(x, y) — no trigger element at all.

Ready

JavaScript

const menu = Look.lkMenu('#more', {
  items: [
    { id: 'rename', text: 'Rename', icon: 'edit', shortcut: 'F2' },
    { type: 'separator' },
    { id: 'share', text: 'Share', items: [{ id: 'link', text: 'Copy link' }] },
    { id: 'delete', text: 'Delete', icon: 'delete' },
  ],
  trigger: 'click',                 // 'click' | 'contextmenu' | 'hover' | 'manual'
  placement: 'bottom-left',
  beforeAction(item, { event, checked }) {
    if (item.id === 'delete') return confirm('Delete this item?');
  },
  onAction(item, { source, component }) { console.log(item.id, source); },
  onOpen(component) {},
  onClose(reason, component) {},    // 'escape' | 'outside' | 'action' | 'tab' | 'toggle' | 'hover' | 'api' | 'destroy'
});

Look.lkMenu('#canvas', { trigger: 'contextmenu', items });   // opens at the pointer
Look.lkMenu({ items }).open(120, 80);                         // manual, no trigger element

menu.setChecked('wrap', true);
menu.destroy();
