Slider

lkSlider(el, opts) — drag-to-set-value range control

Live Demo

Default (drag, click or use arrow keys)

Positive color (step 10)

Accent, dense (0 – 1, step 0.1)

Negative color, disabled

HTML

<div id="volume" aria-label="Volume">
  <div class="lk-slider__track">
    <div class="lk-slider__fill"></div>
    <div class="lk-slider__thumb">
      <span class="lk-slider__label"></span>
    </div>
  </div>
</div>

JavaScript

const vol = Look.lkSlider('#volume', {
  min: 0, max: 100, value: 50, step: 5,
  onChange(v) { console.log(v); },
});

vol.value;              // 50
vol.value = 75;
vol.min; vol.max; vol.step;
vol.destroy();
