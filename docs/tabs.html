Tabs

lkTabs(el, opts) — tab list from options or <ul> markup; panels from text, HTML, a template or a URL

This page is opened from file://, where browsers block fetch(). The URL tabs show their error state — serve the folder (e.g. npx serve .) or open the GitHub Pages docs to see them load.

Built from options — every content type

The tab list is built inside #tabs-basic; panels go into the container #tabs-basic-panels.

From existing <ul><li> markup

Items keep their markup. data-url, data-select, data-template, data-render, data-name, data-disabled and <a href="#panel"> are read; opts.tabs[i] adds to / overrides item i.

Render modes

Each panel shows how many times its content function ran and keeps a text box so you can see whether state survives switching tabs.

render: 'lazy' (default) — rendered on first activation, then kept.

render: 'eager' — every panel rendered up front.

render: 'active' — rendered on every activation, destroyed on leave.

Dynamic tabs & beforeChange

Type in the Draft tab, then try to leave it: beforeChange asks first.

JavaScript

const tabs = Look.lkTabs('#tabs', {          // a container (list is built) or an existing <ul>
  container: 'tab-panels',                     // element id (or Element) receiving the panels
  variant: 'line',                             // 'line' | 'pill' | 'box'
  orientation: 'horizontal',                   // or 'vertical'
  render: 'lazy',                              // 'lazy' | 'eager' | 'active'
  tabs: [
    { name: 'overview', title: 'Overview', content: 'Plain text, escaped' },
    { name: 'details',  title: 'Details',  html: '<b>Raw</b> HTML' },
    { name: 'team',     title: 'Team',     url: '/partials/team', select: '#team' },
    { name: 'stats',    title: 'Stats',    content: async (panel) => buildChart(await api.stats()) },
  ],
  onChange(name, prev) { console.log(prev, '→', name); },
});
tabs.select('team');
tabs.reload('team');      // fetch again
tabs.destroy();
