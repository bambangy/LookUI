Modal

lkModal(modalEl, { trigger, onOpen, onClose }) — dialog with focus trap

Live Demo

Modal Title

This modal uses Look.lkModal() with focus trapping.

Dense & calm variants

.lk-modal--dense tightens spacing; .lk-modal--calm replaces the SweetAlert pop/slide with a plain rise/fade.

Dense modal

Less padding, smaller title, tighter footer gap.

Calm motion

Rises slightly on open and drops/fades on close.

HTML

<button id="trigger">Open</button>
<div id="modal-container">
  <div class="lk-modal-overlay">
    <div class="lk-modal" role="dialog" aria-modal="true">
      <div class="lk-modal__header">…</div>
      <div class="lk-modal__body">…</div>
      <div class="lk-modal__footer">…</div>
    </div>
  </div>
</div>

JavaScript

const modal = Look.lkModal('#modal-container', {
  trigger: '#trigger',
  onOpen(modal) {},
  onClose(reason, modal) {},   // 'close' | 'escape' | 'toggle' | custom
});
modal.open();
modal.close();
modal.toggle();
modal.destroy();
