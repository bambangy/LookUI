Form

lkForm(form, opts) — values, dirty tracking, reset, validation and submit for a <form>, without reactive state

Live form

Components (textbox, dropdown) are registered; the plain checkbox, radios, textarea and number input are read by name. Edit something: the dirty badge and the change list update. Submitting validates, then shows the values; the e-mail taken@example.com simulates a server 422.

JavaScript

    
const email = Look.lkTextbox('#email', { label: 'E-mail', rules: ['required', 'email'] });
const country = Look.lkDropdown('#country', { items, name: 'country' });

const form = Look.lkForm('#signup', {
  fields: { email, country },          // components by name; every other named control is read natively
  warnOnLeave: true,                   // "leave site?" prompt while dirty
  onChange(values, { name, source }) { console.log(name, source, values[name]); },
  async onSubmit(values) {             // runs after validation; throw a 422 body to map errors onto fields
    await api.post('/signup', values);
    form.commit();                     // saved: this is the new baseline
  },
  beforeSubmit: (values) => confirmTerms() || false,
});

form.getValues();            // { email, country, plan: 'free', newsletter: false, seats: 1, … }
form.setValues({ email: 'a@b.co' });   // silent
form.dirty; form.changes();  // { email: { from: '', to: 'a@b.co' } }
form.reset();                // back to the baseline, not the markup defaults
form.notify('country');      // for components that do not emit a native input / change event
form.destroy();              // listeners, the novalidate attribute, the unload prompt
