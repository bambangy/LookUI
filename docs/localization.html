Localization

Look.i18n — one registry for every label, placeholder, message and aria text

Live demo

Switch the language: the components below re-render their texts without being re-created. Only the keys in the small demo dictionaries are translated — everything else falls back to English.

How it works

Every user-facing string in the library is a key such as upload.placeholder.single or common.cancel. Components look a key up in this order and stop at the first hit:

  1. an explicit text option of the component (placeholder, loadingText, removeLabel, messages, …) — still supported and always wins;
  2. the instance text option / component.text = {…};
  3. the active locale (id-ID falls back to id);
  4. the fallback locale (en);
  5. the built-in English defaults — and if even that is missing, the key itself (plus one console warning).

1 — Translate the whole page

// A flat { key: message } dictionary per locale. Only add what you want to change.
Look.i18n.set('id', {
  'common.cancel': 'Batal',
  'common.ok': 'OK',
  'common.search': 'Cari',
  'validation.required': '{label} wajib diisi',
  'upload.placeholder.single': 'Pilih berkas…',
  'upload.summary': { other: '{count} berkas · {size}' },     // plural forms
});

Look.i18n.use('id');        // switch — mounted components update themselves

Look.i18n.locale;           // 'id'
Look.i18n.defaults('upload');   // the English template for one component, ready to translate
Look.i18n.keys();               // every key the loaded components define

2 — Override one component

const cv = Look.lkUpload('#cv', {
  label: 'Resume',
  text: {
    'placeholder.single': 'Attach your resume',    // relative to the component (upload.placeholder.single)
    'common.remove': 'Delete',                       // shared keys are absolute
  },
});

cv.text = { 'placeholder.single': 'Drop it here' };   // runtime, re-renders immediately

3 — Message formats

'Hello {name}'                                   // placeholders: t('x', { name: 'Ana' })
{ one: '{count} file', other: '{count} files' }  // plurals by Intl.PluralRules(locale), also '=0': 'No files'
(params) => `${params.count} berkas`               // or a function

4 — MVC / server-rendered pages

<!-- Razor: emit the user's dictionary once, before the components are created -->
<script>
  Look.i18n.set('id', @Html.Raw(Json.Serialize(Localizer.AllFor("Look"))));
  Look.i18n.use('@CultureInfo.CurrentUICulture.Name.ToLowerInvariant()');   // e.g. 'id' or 'id-id'
</script>

// Plain JS / SPA: lazy-load a locale file
const dict = await (await fetch('/i18n/look.id.json')).json();
Look.i18n.set('id', dict);
Look.i18n.use('id');

Dates, numbers, sizes

Anything formatted by the library follows the active locale through Intl: lkDate month and weekday names (its locale option defaults to Look.i18n.locale), file sizes in lkUpload, country names in lkPhone (Intl.DisplayNames). Units and words that Intl cannot supply (KB, "Now", "AM") are ordinary keys.
